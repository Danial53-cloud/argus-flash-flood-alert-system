# ARGUS — Tools and Technologies

**Table 2: Proposed Tools and Technologies**

| #  | Tools and Technology         | Purpose                                                                                              |
| -- | ---------------------------- | ---------------------------------------------------------------------------------------------------- |
| 1  | HTML, CSS, JavaScript        | Build the web interface that users see and interact with.                                            |
| 2  | Leaflet.js                   | Display the interactive map and draw flood-prone channels on it.                                     |
| 3  | OpenStreetMap                | Provide the base map for displaying geographic features.                                             |
| 4  | GeoJSON                      | Store flood-channel coordinates in a format that the map can read.                                   |
| 5  | geojson.io / QGIS            | Trace and digitize flood channels and export them as GeoJSON files.                                  |
| 6  | Open-Meteo API               | Provide rainfall forecast data for the Bagh region.                                                  |
| 7  | Python with Flask            | Run the backend, retrieve forecasts, evaluate risk thresholds, and provide alert results to the map. |
| 8  | MySQL                        | Store flood-channel data, retrieved forecasts, and alert status.                                     |
| 9  | Figma                        | Design interface mockups before implementation.                                                      |
| 10 | Git and GitHub               | Manage version control, repository collaboration, and project tasks.                                 |
| 11 | Visual Studio Code (VS Code) | Write and edit project code.                                                                         |

**Note:** These are the proposed tools and technologies for ARGUS. Their selection and implementation may be adjusted during development. Flood-prone channel data for Bagh District still requires research and verification; its collection and validation have not yet been confirmed.
