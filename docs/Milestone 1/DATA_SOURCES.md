# ARGUS — Data Sources

This document will record the data sources used in the ARGUS Flash Flood Alert System.

* **Map data:** OpenStreetMap
* **Rainfall forecast data:** Open-Meteo API
* **Flood-prone channel data:** To be researched and verified for Bagh District, Azad Jammu and Kashmir.

The data sources and their suitability will be reviewed during project development.
