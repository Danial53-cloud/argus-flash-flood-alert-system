# ARGUS — Project Scope

## In Scope

* Interactive map of Bagh District, Azad Jammu and Kashmir.
* Display of researched flood-prone channels.
* Rainfall forecast integration using a weather API.
* Threshold-based flood risk alerts.
* Visual display of alerts on the map.

## Out of Scope

* Mobile application development.
* Physical sensors and IoT devices.
* Automated flood-channel detection using satellite imagery.
* SMS and push notifications.
* Expansion to other districts.
